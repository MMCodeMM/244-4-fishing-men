# 🎣 釣魚人圖鑑 - Fishing Men Gallery

## 📖 專案介紹

**釣魚人圖鑑** 是一個專為香港釣魚愛好者設計的綜合性網路應用程式，提供完整的魚類資訊查詢、個人釣魚記錄管理、以及互動式地圖標記功能。

## ✨ 主要功能

### 🏠 首頁 (index.html)
- **魚類輪播展示**：以精美的輪播介面展示各種魚類
- **響應式設計**：支援桌面和手機瀏覽
- **導航功能**：快速前往其他功能頁面

### 👤 會員系統 (register.html)
- **智慧型表單切換**：同一頁面可在「註冊」和「登入」模式間切換
- **即時表單驗證**：輸入錯誤時即時顯示錯誤提示
- **自動登入**：註冊成功後自動登入
- **安全儲存**：使用 localStorage 管理登入狀態

### 📚 魚類圖鑑 (album.html)
- **完整魚種資料庫**：包含 12 種香港常見魚類
- **詳細魚類介紹**：每種魚類都有詳細描述和圖片
- **快速定位**：支援 URL 參數直接跳轉到指定魚類

### 🔍 圖片搜尋 (search.html)
- **圖片上傳識別**：上傳魚類照片進行識別
- **即時預覽**：上傳後立即顯示圖片預覽
- **搜尋結果**：顯示相關魚類資訊（目前顯示所有魚類作為結果）

### 🗺️ 互動式地圖 (map.html)
#### 訪客功能：
- **魚類資訊展示點**：地圖上的綠色圓點顯示魚類棲息地
- **懸停查看資訊**：滑鼠懸停查看魚類詳細介紹
- **快速跳轉**：點擊綠點直接跳轉到魚類圖鑑

#### 會員專屬功能：
- **釣點標記**：點擊地圖任意位置新增個人釣點記錄
- **標記管理**：右鍵點擊標記進行編輯或刪除
- **資料同步**：標記資料儲存至伺服器，跨裝置同步
- **智慧分層**：用戶標記顯示在最上層，不被魚類資訊點遮蔽

### 📸 我的圖鑑 (my_album.html)
- **個人收藏管理**：管理個人上傳的魚類照片
- **地圖整合**：從地圖標記可直接跳轉到此頁面
- **會員限定**：需登入後才能使用

## 🛠️ 技術架構

### 前端技術
- **TypeScript**：提供型別安全的開發體驗
- **原生 HTML/CSS/JavaScript**：輕量化設計，快速載入
- **響應式設計**：適配各種螢幕尺寸
- **Swiper.js**：實現流暢的輪播效果

### 後端技術
- **Node.js + Express**：高效能伺服器框架
- **TypeScript**：統一前後端開發語言
- **JSON 檔案儲存**：輕量化資料管理
- **Session 管理**：安全的會員狀態管理

### 建置工具
- **esbuild**：快速打包客戶端程式碼
- **ts-node-dev**：開發時自動重載
- **npm-run-all**：並行執行多個建置任務

## 🚀 快速開始

### 系統需求
- Node.js 16.0 或以上版本
- npm 或 yarn 套件管理器

### 安裝步驟

1. **複製專案**
```bash
git clone https://github.com/MMCodeMM/244-4-fishing-men.git
cd 244-4-fishing-men
```

2. **安裝依賴**
```bash
npm install
```

3. **啟動開發伺服器**
```bash
npm start
```

4. **瀏覽應用**
開啟瀏覽器前往 `http://localhost:3000`

### 可用指令
- `npm start` - 啟動開發伺服器（包含自動重載）
- `npm run build:server` - 編譯伺服器端 TypeScript
- `npm run build:client` - 編譯客戶端 TypeScript
- `npm run serve` - 僅啟動伺服器（不含自動重載）

│   ├── main.ts            # 主伺服器
│   ├── data.ts            # 資料型別定義
│   ├── user.ts            # 使用者相關 API

## 🔧 開發指南

### 新增魚類資料
1. 在 `server/fish.json` 中新增魚類資料
2. 將對應圖片放入 `public/data/fish/` 目錄
3. 重新啟動伺服器即可生效

### 自訂樣式
- 主要樣式檔案：`public/styles.css`
- 支援響應式設計的媒體查詢
- 使用 CSS 變數統一管理顏色主題

### 擴充功能
- 前端功能：在 `client/` 目錄新增 TypeScript 檔案
- 後端 API：在 `server/` 目錄擴充路由
- 資料儲存：使用 `PData/` 目錄儲存 JSON 資料
